# Ideas and research backlog

**Status:** exploratory. These are hypotheses, not features approved for the initial release. Promote an idea only after a documented decision.

| Idea | Value to investigate | Main uncertainty |
| --- | --- | --- |
| Scan quality score | Explain whether a photograph is fit for dimensioned tracing | Reliable thresholds across cameras and materials |
| Multiple calibration references | Detect inconsistent scale or lens effects | Usability and reference placement |
| Automatic notch/mark recognition | Reduce cleanup of sewing and craft patterns | False positives and varied notation |
| Material remnant library | Reuse real offcuts across sessions | Capturing irregular shapes efficiently |
| Defect-aware cutting | Avoid stains, holes and damaged regions | Manual annotation versus automatic detection |
| Pattern matching in Nest | Align repeated motifs across cut parts | Computational cost and material-specific rules |
| Layout comparison | Compare waste, speed and physical cutting practicality | Choosing fair, interpretable metrics |
| Print profile presets | Reduce repeated page/printer setup | Driver-specific behavior and portability |
| Shareable diagnostic report | Explain failures without distributing source files | Privacy and report completeness |
| Visual diff of pattern revisions | Show changed dimensions or contours | Robust geometric registration |

## Idea template

When adding an idea, record:
- Problem and target user.
- Input and expected output.
- Evidence or observed workflow.
- Proposed approach and main risks.
- How success would be measured.
- Decision: explore / accept / reject / defer.

## Guardrails

Do not turn Cutmetry into a course platform, a mandatory cloud service, or three disconnected modules. Avoid claiming automatic precision, perfect printing, or globally optimal nesting without verification.
